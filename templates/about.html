What is YouTube Sentiment Analysis?

This app analyzes sentiments expressed in YouTube comments using natural language processing (NLP) techniques. It provides insights into the general sentiment (positive, negative, neutral) of the comments related to a specific video or topic.

How It Works

The app uses a Flask backend to process user requests and interacts with a machine learning model trained on sentiment analysis. When a user inputs a YouTube video URL or keyword, the app fetches relevant comments, analyzes them using the model, and displays the sentiment analysis results.
